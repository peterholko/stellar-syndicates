# Titan · user-reference hull concept

`titan-reference.png` is a 1774 × 887 five-view design proposal: TOP, BOTTOM, FRONT, BACK, and SIDE. The two user-supplied shape references are preserved in `references/`.

This version follows their low, broad, layered angular spacecraft construction: a blunt stepped prow, integrated side spars, broad rear shoulders, deeper armored keel and two substantial stern engine blocks. Each engine block has two vertical oval exhausts. Titanium armor, gunmetal recesses, restrained brass fittings and cyan lighting retain the Stellar Syndicates material family. The underside has its own completed armor, radiator and machinery layout.

Generated using the built-in image_gen tool; the complete generation prompt and input provenance are in `prompts.json`. This is illustrated modeling reference with interpreted elevations, not dimensioned CAD. This proposal has not replaced the game artwork or created a 3D model.
