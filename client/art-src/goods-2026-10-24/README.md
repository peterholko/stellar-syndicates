# Resource icon masters

`image_gen` tool using its prompt in `docs/resource-icon-prompts.md`, as part of
the shipbuilding art delivery. It is a native 1254 × 1254 RGBA PNG with genuine
transparency and a centred silhouette filling 85.3% of the canvas. Its generated
bytes are preserved unchanged.

hash, dimensions, bounds and transparency. The other twelve resource prompts
in that brief remain to generate.
