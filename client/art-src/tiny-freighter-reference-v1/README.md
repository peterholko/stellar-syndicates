# Tiny Freighter reference

Final artwork: [tiny-freighter-reference.png](tiny-freighter-reference.png)

Four labeled views: top, bottom, side, and front. The underside includes dedicated belly armor, maintenance hatches, grilles, and engine details. The front is a head-on elevation.

Created September 29, 2026 using the built-in imagegen tool. No Blender or game code changes.
