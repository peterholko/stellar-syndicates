# Titan · anvil-bow concept

`titan-reference.png` is a five-view design proposal showing FRONT, BACK, TOP, BOTTOM, and SIDE. This third direction follows the user’s rejection of both the three-pronged Titan and the plain wedge concept.

The new silhouette uses one continuous armored hull, a broad transverse anvil bow, stepped shoulders, an offset aft command tower, a recessed flight/service deck, lateral hangars, and a central octagonal reactor cover. Pale titanium armor, charcoal structure, brass details, and cyan lights retain the game’s material family. The underside has a distinct finished panel and radiator layout.

Generated using the built-in image_gen tool. The complete generation prompt is in `prompts.json`. This is concept artwork with interpreted elevations, not a dimensioned CAD drawing. No game art or 3D model has been replaced.
